# ВИЖУ — уникальный ИИ-ассистент для помощи незрячим и слабовидящим (монорепозиторий)

### Что из себя представляет ВИЖУ?

Это в перспективе первый на территории Российской Федерации (после ухода Be My Eyes с рынка) круглосуточный ИИ-ассистент для незрячих и слабовидящих людей, который работает в связке с моделями GigaChat-2-Max, Yandex Vision OCR и Yandex Speech-to-text для оказания комплексной помощи незрячему в случае отсутствия других способов это сделать. 
#### ВИЖУ предлагает следующие возможности:
1. Полная поддержка экранных дикторов VoiceOver и TalkBack за счет изначального проектирования интефрейса под них, с соблюдением всех стандартов a11y. Соответствие WCAG заложено на уровне архитектуры, продуманный фокус-порядок, ARIA-роли и aria-live-регионы для динамического контента плюс семантическая дизайн-система.
2. Круглосуточный ИИ-ассистент, который опишет окружение по фотографии или поможет прочитать текст с чека, распознать купюру, или любую другую надпись с применением технологии OCR.
3. Возможность обсудить с ИИ-ассисентом сделанную фотографию и уточнить детали, а также история данных обсуждений.
4. WebRTC сервер, работающий с применением LiveKit, и волонтерская система, обеспечивающие видеосвязь волонтера с незрячим для персональной помощи последнему.
5. Мобильная версия приложения, предлагающая больше возможностей за счет работы с нативным кодом без веб-прослойки.

### На данный момент продукт находится в состоянии активной разработки.

Бета-версию веб-приложения вы можете посмотреть на:
1. https://vizhu.su - ознакомительная страница
2. https://app.vizhu.su - само приложение
3. Мобильная версия на Android и IOS разрабатывается параллельно с веб-версией и пока недоступна для тестов.

(OTP-аутентификация работает, но могут возникнуть трудности с доставкой сообщений. Если вас заинтересует возможность протестировать проект, пожалуйста, напишите мне)

Структура монорепозитория:

```
viju/
  infra/      - docker-compose, nginx, CI/CD
  api/        - Бэкенд - обработка аутентификации, webrtc, Gateway для связи с AI-сервисами
  front/      - Фротенд-часть, включая веб версию и мобильную
  ai/         - AI-микросервис на FastApi для общения с внешними API Gigachat и Yandex OCR/STT
  landing/    - сабмодуль с ознакомительной страницей
```
